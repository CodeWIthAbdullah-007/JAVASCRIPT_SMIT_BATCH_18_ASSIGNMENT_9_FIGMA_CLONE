# EmbedSocial Landing Page Clone

A modern, fully responsive landing page inspired by EmbedSocial, designed using HTML, Bootstrap 5, and pure CSS. This project focuses on clean UI, smooth interactions, hover animations, and professional front-end practices.

## 🔥 Features

- Fully responsive design (mobile, tablet, desktop)
- Smooth scrolling navigation
- Active navbar link highlight on scroll
- Custom mouse text selection color
- Animated buttons with hover effects
- Logo hover animation using ::before and ::after
- Feature cards with hover lift and box-shadow
- Clean layout using Bootstrap Grid
- External CSS & JS files
- No inline styles, no comments (clean code)

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript (Vanilla)

1. Download or clone the repository
2. Open `index.html` in any modern browser
3. Make sure all folders (css, js, images) are in the same root directory
